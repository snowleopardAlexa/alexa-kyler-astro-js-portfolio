  I researched and designed a complete UX/UI web app for TNR volunteers,
  leading the full process from user interviews and problem discovery
  through wireframes, prototypes, and high-fidelity UI design.
decisions:
  - "Started from user interviews rather than assumptions, since TNR workflows aren't documented anywhere online."
  - "Moved through low- and high-fidelity wireframes before prototyping, testing structure before testing visual design."
  - "Validated the prototype with real volunteer user testing before finalizing the UI."
